# 应用统计期末作业：应用统计智能体测评任务集

## 作业要求

1. 选择一个应用场景，明确要研究的问题，可以来源于狗熊会案例或者 Kaggle 竞赛题目。
2. 参照课程内容，将应用统计的环节进行分解（建议分成：问题陈述与精练、数据探索性分析、建模分析、结果解释四个环节）见参考案例。
3. 针对每个环节，设计问题，要求问题难度具有区分度，至少三个难度，可以与 AI 协作完成，但要结合课程内容对难度确定的原则进行解释。
4. 调用至少三个大模型，对每个问题进行回答，并对答案进行评价排序，给出关于排序准则的解释。
5. 将质量高的回答整合成一份完整的数据分析报告。

## 评分准则

1. 提交材料：问题优化过程材料、问题与答案以及对答案评价的准则。
2. 场景典型性：选择实际场景的真实需求作为研究问题的出发点。
3. 问题打磨程度：设计问题不能太随意。
4. 在问题难度判断、答案质量判断过程中体现对课程内容的理解。
5. 报告本身完整性。
6. 加分项：鼓励将任务集合开发流程沉淀为 Skill；鼓励发挥主动性，对应用统计智能体测评体系构建提出设想。
